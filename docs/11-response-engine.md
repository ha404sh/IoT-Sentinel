# 11 – Response Engine

## Policy

| Severity  | Response                                      |
|-----------|-----------------------------------------------|
| LOW       | Log                                           |
| MEDIUM    | Warning                                       |
| HIGH      | Alert + Enhanced Monitoring                   |
| CRITICAL  | Alert + Logical Isolation + Incident Creation |

## Recovery

Controlled transition `ISOLATED → ACTIVE` is supported and audited.
